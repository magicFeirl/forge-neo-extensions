# Forge Neo Extensions (非官方插件收集与归档)

本仓库用于收集并归档社区（如 Bilibili、各大论坛等）中分享的、**未在 GitHub 上公开发布**的 SD WebUI Forge Neo（[sd-webui-forge-classic](https://github.com/Haoming02/sd-webui-forge-classic)）扩展插件，便于备份、更新与社区用户查找下载。

## 🚀 安装方法 (Installation)

1. 点击仓库右上角的 **Code -> Download ZIP** 下载整个仓库解压，或者使用 git 克隆本仓库；
2. 将需要的插件文件夹（例如 `sd-forge-anima-camera`）复制到你的 Forge Neo 安装目录下的 `extensions/` 文件夹中：
   ```text
   <forge-neo>/extensions/sd-forge-anima-camera/
   ```
3. 确保目录结构正确（如 `<forge-neo>/extensions/sd-forge-anima-camera/scripts/` 存在）；
4. 重启 Forge Neo 网页即可使用。具体插件依赖模型及配置请参考各插件目录内的 `README.md`。
